## 二、页面与路由

✅ `GET /ui` 问答首页可访问。

✅ `POST /ui/profile` 可初始化昵称和匿名身份。

✅ `POST /ui/conversations` 可创建新会话。

✅ `GET /ui/conversations/{conversation_id}` 可切换历史会话。

✅ `POST /ui/conversations/{conversation_id}/ask` 可提交问题并刷新页面主区。

✅ `GET /ui/conversations/{conversation_id}/messages/{message_id}/citations/{citation_index}` 可查看引用详情。

✅ `GET /ui/conversations/{conversation_id}/messages/{message_id}/retrieval-results/{result_index}` 已具备检索结果详情接口能力，但当前前端不直接暴露入口。

✅ `GET /ui/admin/login` 可渲染 admin 登录页。

✅ `POST /ui/admin/login` 可提交登录并写入 admin cookie。

✅ `POST /ui/admin/logout` 可清理 admin cookie。

✅ `GET /ui/admin/ingest` 可渲染导入管理页。

✅ `POST /ui/admin/ingest` 可提交导入任务并返回更新后的管理页。

✅ `GET /ui/admin/ingest/status` 可刷新导入状态片段。

✅ `DELETE /ui/admin/ingest/{ingest_run_id}` 可取消任务并返回更新后的状态片段。

✅ `GET /ui/admin/ingest?lookup_source_path=...` 可按路径查询当前或最近一次任务状态。
